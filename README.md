# Budget Planner (Java)

## Description
The Budget Planner is a Java console application that helps users calculate their budget by taking income, expenses, debts, and tax rate as input.  
It calculates monthly and yearly savings based on the provided data.

This project was created as a practice application to demonstrate object-oriented programming concepts in Java.

## Features
- Input monthly income
- Input expenses and multiple debts
- Apply country tax rate
- Calculate net income
- Calculate monthly savings
- Calculate yearly savings

## Technologies Used
- Java
- Java Scanner class
- Object-Oriented Programming (OOP)

## How the Program Works
1. The user enters their income.
2. The user enters expenses and tax rate.
3. The user inputs the number of debts and their values.
4. The program calculates:
   - Net income after tax
   - Monthly savings
   - Yearly savings

## How to Run
1. Open the project in any Java IDE (IntelliJ, Eclipse, NetBeans, or Android Studio).
2. Compile and run the `BudgetPlanner.java` file.
3. Follow the instructions shown in the console.

## Example Output
- Income: 5000  
- Expenses: 2000  
- Debts: 500  
- Tax Rate: 10%  
- Monthly Savings: 2000  
- Yearly Savings: 24000
